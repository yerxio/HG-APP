# HG-APP V1.0

红果视频流广告过滤 LSPosed 模块，发布附件为**拦截版**。

## 适配与安装

- 目标应用：`com.phoenix.read`，版本 `7.4.5.32 / 74532`。
- 模块包名：`local.hongguore.feedfilter`，版本 `1.0`，版本号 `2`。
- 需要已正常运行的 LSPosed。APK 直接安装，不是 KernelSU 刷入 ZIP。
- 在 LSPosed 中启用模块，作用域只选择红果，然后彻底停止并重新打开红果。
- 发布 APK 沿用原型签名，可覆盖安装先前的观察版或拦截版。

## 功能

- 按模型识别普通商业广告、横屏广告包装和自然流推广素材。
- 在视频列表单项插入及替换之前拒绝广告对象，其他类型交给原逻辑。
- 支持版本检查及有限诊断日志，不修改红果 APK 或系统 hosts。

## 已知限制

仅适配指定目标版本，不保证覆盖所有广告页面或插入路径。正常视频播放、真实广告 BLOCK 命中及横竖屏表现仍需实机回归。已确认原型观察版的广告识别和拦截版加载；发布准备时尚无保存的真实 BLOCK 命中记录。

停用本模块并重启红果即可撤销运行时 Hook。需要完整移除时卸载本模块，不必清除红果数据。

附件包含 `HG-APP-V1.0.apk` 与 `SHA256SUMS.txt`。仓库不包含原始目标 APK、反编译代码、私钥或设备原始日志。
